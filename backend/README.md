# CyberShield AI - FastAPI Backend Service

This directory contains the Python FastAPI backend service for **CyberShield AI**, as specified in the pitch deck architecture (Slide 4).

## Setup & Running

1. **Install Dependencies**:
```bash
pip install -r requirements.txt
```

2. **Run Server**:
```bash
python main.py
```
Or:
```bash
uvicorn main:app --reload --port 8000
```

3. **API Documentation**:
Once running, interactive OpenAPI / Swagger docs are available at: `http://localhost:8000/docs`
